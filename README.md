# strudel-samples

Original vocal, instrument and effect samples for Strudel, made for a deep house track in F minor at 122 BPM.
Voices are custom-designed synthetic voices (ElevenLabs); all lines are original. Loops are cut to exact bar lengths at 122 BPM.

```javascript
samples('github:justusaugust/strudel-samples/v3')
```

Branch `v3` is the lean pack (FLAC and MP3, about 15 MB). `main` holds the older WAV version.
