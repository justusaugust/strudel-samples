# strudel-samples

Original vocal, instrument and effect samples for Strudel, made for a deep house track in F minor at 122 BPM.
Voices are custom-designed synthetic voices (ElevenLabs); all lines are original.

```javascript
samples('github:justusaugust/strudel-samples')
```

| name | n | what |
|---|---|---|
| `nl_morning` | 6 | "Don't let the morning in": 0-2 female (whisper, low, drawn), 3-5 male |
| `nl_epic` | 3 | the same line, deep male, three slow takes |
| `nl_fr` | 10 | dry French lines: 0-3 male, 4-9 female (see file names) |
| `nl_pre` / `nl_hit` | 2 each | pre-drop pickup, exactly 2 bars, ending on the bar line; the last word as a separate hit with a tuned tail. 0 English, 1 French |
| `nl_tail` | 8 | phrases through a resonator tuned to Fm9, stereo |
| `nl_chop` | 10 | single words of the English line: 0-4 female, 5-9 male |
| `nl_sung` / `nl_sungbar` | 2 / 7 | sung hook, 8 bars (dry, wet) and cut into one-bar phrases |
| `nl_chant` | 2 | wordless female chant, free time, around C minor / F dorian (dry, wet) |
| `nl_duduk` | 2 | duduk melody, free time, F harmonic minor (dry, wet) |
| `nl_oud`, `nl_darbuka` | 1 each | 4-bar loops at 122 BPM; the oud sits on F |
| `nl_riser`, `nl_vinyl`, `nl_wind` | 1 each | exactly 4 bars at 122 BPM |
| `nl_swell` | 1 | reverse swell, exactly 2 bars, peak at the end |
| `nl_impact`, `nl_boom`, `nl_downlift`, `nl_inhale`, `nl_sand` | 1 each | one-shots |
