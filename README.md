# strudel-samples

Original vocal and effect samples for Strudel, made for a deep house track in F minor at 122 BPM.
Voices are custom-designed synthetic voices (ElevenLabs), lines are original.

```javascript
samples('github:justusaugust/strudel-samples')
```

| name | count | what |
|---|---|---|
| `nl_morning` | 6 | "Don't let the morning in": 0-2 female (whisper, low, drawn), 3-5 male |
| `nl_stanna` | 6 | "Stanna kvar": same order |
| `nl_chop` | 14 | single words: 0-4 morning f, 5-9 morning m, 10-11 stanna f, 12-13 stanna m |
| `nl_tail` | 8 | phrases through a resonator tuned to Fm9, stereo, long |
| `nl_sung` | 2 | sung hook, 8 bars at 122 BPM: 0 dry, 1 wet |
| `nl_sungbar` | 7 | the sung hook cut into one-bar phrases |
| `nl_riser` | 1 | noise riser, exactly 4 bars at 122 BPM |
| `nl_vinyl` | 1 | vinyl crackle, exactly 4 bars |
| `nl_impact`, `nl_downlift`, `nl_crowd` | 1 each | drop hit, falling sweep, club crowd |
